# 版本 1.2.0

* 发布日期：2026-08-09
* 包含迭代：DEV-20260809-001（SUCCESS）
* 成员接入：公司成员可从页面申请账号，完成邮箱确认后等待管理员授权。
* 权限治理：管理员必须为申请人分配至少一个角色；只有 ACTIVE 成员可以登录。
* 邮件能力：开发环境记录确认链接，生产环境使用 STARTTLS SMTP，并校验 HTTPS 公网地址与公司邮箱域名白名单。
* 数据库变更：`000014_member_registration` 增加成员资料、确认/授权状态字段和一次性邮箱确认 Token 表。
* 安全性：原始确认 Token 不落库，重复申请与重发不暴露账号存在性，成员状态变化写入审计日志。
* 兼容性：原有用户名密码登录继续可用；既有 Demo/历史用户会迁移为 ACTIVE，空库已验证可完整执行至 1.2.0。
* 已知限制：升级旧数据卷前必须确认已发布 migration 校验值一致；当前本地旧卷存在既有 `000012` 校验值不一致。暂未实现企业 SSO/SCIM、邀请制注册、找回密码和管理员强制下线。
