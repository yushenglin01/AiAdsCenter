# 版本 0.4.1

* 发布日期：2026-08-04
* 包含迭代：DEV-20260804-005（SUCCESS）
* 新增功能：永久迭代/发布/ADR/契约归档体系；Prompt 与 Schema 1.0.0；归档检查脚本。
* 修改功能：SQL migration runner 替代 AutoMigrate；Agent 任务与用量补齐契约版本追踪。
* 修复问题：修复 Prompt、Schema、结果和用量之间不能完整追溯的问题；修复 Web 容器 `localhost` 探针造成的伪不健康状态。
* 不兼容变更：无 HTTP BREAKING CHANGE；数据库新增非空字段并带历史默认值。
* 数据库变更：`000000_schema_migrations` 定义历史表；`000005_version_agent_contracts` 新增 agent_tasks.schema_name/schema_version 与 model_usage_records.prompt_name/schema_version。
* 接口变更：响应中的 task/usage 增加版本追踪字段，属于向后兼容字段新增；当前 OpenAPI 版本更新为 0.4.1。
* Prompt/Schema：运行时切换到 `*_v1.0.0.txt` 和 `business-agent-output-v1.0.0.json`；0.4.0 旧版已归档。
* 部署要求：镜像必须包含 `migrations/` 与 `configs/schemas/`；数据库用户需有 CREATE/ALTER 权限。
* 升级步骤：备份数据库；部署 0.4.1；runner 由 000000 引导历史表，登记 000001–000004 校验值并执行 000005；检查 schema_migrations；运行全套测试和 E2E。
* 回滚步骤：先停写 Agent 任务，备份新增列，人工执行 000005 down 并删除对应 schema_migrations 记录，再回退 0.4.0；降级将丢失新增版本追踪值。
* 已知问题：真实 OpenAI-compatible 模型兼容性与生产级 migration 故障演练 NOT_VERIFIED；阶段五未开始。
* 验收结果：Go 单测/静态检查、前端 lint/test/build、归档检查、Compose 健康与 stage4 E2E 均通过。
