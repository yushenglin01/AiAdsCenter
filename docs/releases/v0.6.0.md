# 版本 0.6.0

* 发布日期：2026-08-04
* 包含迭代：DEV-20260804-007（SUCCESS）
* 新增功能：建议中心、审批中心、审计日志、模型用量、Dashboard 运营指标、WAITING_APPROVAL 工作流。
* 修改功能：高风险建议由 SYSTEM_AGENT 请求审批；最后一个待审批请求完成后异步任务才进入 SUCCEEDED。
* 修复问题：补齐审批决策闭环、被拒决策审计 task_id、建议/审批/任务/审计事务一致性。
* 不兼容变更：新生成的高风险任务会先返回 WAITING_APPROVAL，而不是直接 SUCCEEDED；客户端应把它视为分析完成但流程待人工决策。审批详情字段由 reviewed_* 语义统一输出为 decided_*。
* 数据库变更：`000007_approval_audit_and_operations` 扩展 approval_requests 并创建 audit_logs；旧审批按 recommendation/report 回填。
* 接口变更：新增 recommendations、approvals、model-usage、audit-logs、dashboard/operations；审批 POST 可能返回 400/403/404/409。
* Prompt/Schema：无变更，继续使用 Business Agent Prompt/Schema 1.0.0。
* 部署要求：API 必须先完成 000007 和 Demo seed，再启动 Worker；SYSTEM_AGENT 用户状态为 SYSTEM，不能登录。
* 升级步骤：备份数据库；部署 API 并确认 000007；部署 Worker/Web；检查旧审批回填；验证角色审批和 audit_logs。
* 回滚步骤：停止新分析和审批；导出 audit_logs 与新审批字段；执行 000007 down 并同步 schema_migrations；回退 0.5.0。已决策建议状态需要在回滚前人工评估。
* 已知问题：审计表当前依靠应用追加约束，未接入 WORM 存储；通知、生产 Trace、真实模型成本和外部平台均 NOT_VERIFIED。
* 验收结果：Go、前端、Compose、Stage4/Stage5 回归、Stage6 审批治理 E2E、迁移与归档检查全部通过；详见 DEV-20260804-007。
