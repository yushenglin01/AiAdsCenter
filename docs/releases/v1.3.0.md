# 版本 1.3.0

* 发布日期：2026-08-09
* 包含迭代：DEV-20260809-002（SUCCESS）
* 真实连接器：新增 Adjust Report Service 只读拉取，与 AppsFlyer 共用 MMP 规范化、幂等导入和同步审计。
* 自动化：常驻 Worker 可扫描所有租户的 ACTIVE/READY MMP 连接，按配置间隔滚动回看并吸收延迟归因修正。
* 前端：数据导入页可分别配置、启停和手工同步 AppsFlyer 与 Adjust，并统一查看 Provider 同步记录。
* 安全性：MMP API Token 和 Adjust 指标映射只存在于服务端环境；连接器固定官方 HTTPS Host，且只使用 GET 报表接口。
* 数据库变更：无；继续复用 0.9.0 引入的 `mmp_connections`、`mmp_sync_runs` 与 MMP 权威区间写入。
* 兼容性：原有 AppsFlyer 配置、手工同步和标准批次导入保持兼容；自动同步默认关闭。
* 已知限制：真实账号凭证与生产配额尚未端到端核对；Meta、Google、TikTok 仍需标准批次/文件导入，尚无原生只读连接器。
