# 版本 0.9.0

* 发布日期：2026-08-04
* 包含迭代：DEV-20260804-010（SUCCESS）
* 新增功能：AppsFlyer Raw Data Pull API v5 只读连接器、连接状态、同步记录和数据导入页入口。
* 数据语义：安装报告的首开计为 installs/activations；指定付费事件按 AppsFlyer ID 去重为 payers，收入统一请求 USD。
* 可靠性：连接/App ID/日期范围幂等，成功同步事务替换同一范围以吸收回补；429/5xx 有限重试，20 万行/50MB/7 天安全上限，失败保存安全错误分类。
* 数据库变更：`000010_appsflyer_mmp_sync` 新增 mmp_connections 与 mmp_sync_runs。
* 安全性：Token 仅来自服务端环境变量；连接与同步按 tenant_id 隔离并追加审计；连接器只有 GET 权限。
* 已知限制：未使用真实 AppsFlyer Token 联调；只同步非自然量安装与指定付费事件；负收入/退款仍需后续数据模型支持。
* 验收结果：Go vet/全量测试、AppsFlyer Client/Service 单测、Vue 类型检查/7 项测试/生产构建通过。
