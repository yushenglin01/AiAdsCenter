# 开发迭代记录

## 基本信息

* 迭代编号：DEV-20260809-002
* 项目版本：1.3.0
* 日期：2026-08-09
* 状态：SUCCESS
* 目标：在既有 AppsFlyer 闭环上增加 Adjust 原生只读拉取，并让 MMP 连接在完成配置后由常驻 Worker 自动回看同步。

## 实现内容

* 提取 provider-neutral `Fetcher`、输入、结果和安全错误契约，AppsFlyer 保持兼容，Adjust 复用同步服务。
* Adjust 客户端固定访问 `https://automate.adjust.com/reports-service/report`，以 UTC、USD 请求 day/campaign/country/currency 维度和配置的事件指标。
* 新增 Adjust 映射 API 与数据导入页连接面板；AppsFlyer、Adjust 可以为同一游戏独立启停和手工同步。
* Asynq Worker 启动时及固定间隔扫描全部租户连接，以 SYSTEM_AGENT 身份执行滚动回看；每个 Provider 独立限制最大日期范围。
* 成功结果复用 MMP 权威日期区间事务替换，失败保留同步运行、安全错误分类与下一轮重试能力。

## 配置与接口

* 新增 `GAI_ADJUST_API_TOKEN`、三个 Adjust 事件指标 slug、超时/重试/日期范围配置。
* 新增 `GAI_MMP_AUTO_SYNC_ENABLED`、`GAI_MMP_AUTO_SYNC_INTERVAL`、`GAI_MMP_AUTO_SYNC_LOOKBACK_DAYS`。
* 新增 `PUT /api/v1/mmp-connections/adjust`；原有同步接口根据连接 Provider 自动选择客户端。

## 安全与回滚

* API Token 不写数据库、不进入前端响应和同步审计；连接表只保存 App ID/App Token 业务映射。
* Adjust 仅允许官方 HTTPS Host 和 GET 报表路径；没有预算、出价、广告状态或素材写入能力。
* 回滚时关闭 `GAI_MMP_AUTO_SYNC_ENABLED` 并移除 Adjust 环境配置即可停止外部拉取；本迭代没有数据库 migration。
