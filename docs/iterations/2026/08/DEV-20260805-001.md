## 实现内容

* Data Agent 在指标重算前评估广告、MMP、游戏收入和素材数据的覆盖、新鲜度与导入失败数，不再固定报告 VALIDATED。
* Attribution/Creative Agent 输出明确的确定性分析能力；AppsFlyer 只读同步已标记 READY，Adjust 明确 NOT_CONFIGURED。
* 新增 research_sources：来源登记后为 PENDING，仅 ADMIN/MANAGER 可核验；Research Agent 与 Business Agent 只读取 VERIFIED 来源。
* Business Prompt 升级为 1.1.0，明确研究来源只能解释背景，不能替代确定性指标证据。
* Report Composer 记录 generator、版本、研究来源 ID、SHA-256 source digest 和 provenance JSON。
* OpenClaw Agent 变为可执行 Agent，并支持 RUN_FULL_ANALYSIS、GET_WORKFLOW_STATUS、LIST_PENDING_APPROVALS、LIST_NOTIFICATIONS、MARK_NOTIFICATION_READ。
* Agent 工作台新增研究来源登记、审核、空态、错误态与角色感知交互。
* 前端改用 Element Plus 组件级导入，低频控件随路由加载，并按 Vue、Element Plus、ECharts、zrender 拆分第三方缓存块；补齐日期选择器、徽标、数值输入和开关注册。

## 安全与回滚

* Research 来源必须是无凭证 HTTPS URL，登记与核验分离，读取按 tenant/game/campaign/date 隔离并保留审核人与时间。
* Agent 不自由联网；未核验来源不会进入 Prompt，Research 列表外事实不得引用。
* OpenClaw 不提供审批决策或广告平台执行指令；审批仍由人工受控接口完成。
* 回滚前备份 research_sources 与新报告溯源字段；down 会永久删除这些数据。生产执行前需核对 analysis_reports 行数/表大小，并在同 MySQL 8 小版本验证 DDL 算法和锁时间；执行 000011 down 后回退 0.9.0。
