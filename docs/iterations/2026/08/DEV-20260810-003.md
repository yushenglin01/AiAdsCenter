# 开发迭代记录

## 基本信息

* 迭代编号：DEV-20260810-003
* 项目版本：1.4.1
* 日期：2026-08-10
* 状态：SUCCESS
* 目标：在不削弱确定性证据、审批与只读边界的前提下，为 Research、Creative、OpenClaw 和 Report Agent 接入统一 LLM 能力。

## 实现内容

* 增加共享 Agent Intelligence Runtime，复用 OpenAI-compatible Provider，统一记录模型、Prompt、Schema、Token 用量和安全失败分类。
* Research 只归纳 VERIFIED 来源并校验 source_id；Creative 只解释确定性 finding 并校验 finding_id；两者失败时返回确定性结果。
* OpenClaw 增加五类白名单自然语言命令解析，要求显式 ID、置信度门槛、严格 JSON 和 RUN_FULL_ANALYSIS 二次确认。
* Report 增加默认关闭的摘要润色；模型必须回显确定性 source digest，且不能改写事实、发现、建议或来源。
* Business Prompt 升级到 1.2.0，可读取 Creative/Research 工作流上下文，但 Validator 不把 `agent_context` 视为确定性证据。
* Data 与 Attribution 保持纯确定性；Creative 当前不接收媒体文件，不宣称图片或视频理解。

## 配置与兼容性

* 新增 `LLM_RESEARCH_ENABLED`、`LLM_CREATIVE_ENABLED`、`LLM_OPENCLAW_ENABLED` 和 `LLM_REPORT_ENABLED`。
* 默认值依次为 true、true、true、false；`LLM_PROVIDER=mock` 时所有新增增强自动关闭，原演示流程保持不变。
* 结构化 OpenClaw `intent/input` 请求保持兼容，不经过模型。
* 无数据库 migration；复用既有模型用量表和工作流步骤输出。
