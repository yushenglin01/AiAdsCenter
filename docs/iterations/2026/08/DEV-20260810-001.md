# 开发迭代记录

## 基本信息

* 迭代编号：DEV-20260810-001
* 项目版本：1.4.0
* 日期：2026-08-10
* 状态：SUCCESS
* 目标：在受控实时研究与人工核验边界上增加可运营、可恢复、可审计的定时公开网页发现闭环。

## 实现内容

* 新增租户范围 Research Schedule 配置，支持可选游戏/计划、分类、查询、国家、语言、时效、结果数、间隔和启停。
* ADMIN/MANAGER 可配置任务；每租户最多启用 20 个，间隔限制为 60–10080 分钟，启用前必须确认 Provider 结果存储权。
* Worker 按固定轮询扫描到期任务，使用数据库锁 Token、租约和计划时点唯一键认领；崩溃后租约到期可恢复。
* 完全相同的创建请求使用租户内配置幂等键返回既有任务，避免客户端重试重复占用任务额度。
* 新增独立运行记录，保存 Provider、查询哈希、发现/新增/去重/跳过计数和安全错误，不保存响应全文或凭证。
* 自动发现来源标记为 `SCHEDULED_WEB_SEARCH` 并保存任务 ID、Provider、查询哈希和发现时间；状态始终为 PENDING。
* Research 来源库新增自动发现任务配置、启停、下次运行和最近运行结果界面。

## 接口与数据库

* 新增 `GET/POST /api/v1/research/schedules`、`PUT /api/v1/research/schedules/:id` 和 `GET /api/v1/research/schedule-runs`。
* 新增 `000017_scheduled_research` migration，包含 `research_schedules`、`research_schedule_runs` 和来源任务溯源字段。
* 新增 `GAI_RESEARCH_SCHEDULER_ENABLED`、轮询间隔、批量数和租约配置；Compose Worker 显式接收服务端 Web Search 配置。

## 验证

* Research Service 单测覆盖存储权门禁、成功运行、不完整结果跳过、PENDING 来源溯源、供应商限流失败与下周期推进。
* Config 单测覆盖调度器依赖结果存储权及有效轮询/租约配置。
* Go 全量测试与 vet、Vue 类型检查、单测、生产构建、Migration 配对和归档校验通过。
* 未提供真实 Brave Search 账号，本迭代不声称已完成真实配额、计费或结果存储条款核对。

## 安全与回滚

* 原始查询只存在于受租户权限保护的任务配置；审计和运行记录只保存 SHA-256 查询哈希。
* 自动化不会核验来源、启动经营分析、审批建议或写入广告平台；新来源仍需 ADMIN/MANAGER 人工核验。
* 回滚时先设置 `GAI_RESEARCH_SCHEDULER_ENABLED=false` 停止新认领，等待当前租约完成，再执行 000017 down；任务、运行历史及来源任务关联会被删除，来源主体保留。
