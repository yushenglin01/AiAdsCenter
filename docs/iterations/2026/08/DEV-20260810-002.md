# 开发迭代记录

## 基本信息

* 迭代编号：DEV-20260810-002
* 项目版本：1.4.1
* 日期：2026-08-10
* 状态：SUCCESS
* 目标：消除 MMP 数据源的假就绪状态，让首次接入、真实验证和历史成功状态在 API 与页面上保持一致。

## 实现内容

* ACTIVE 且服务端配置齐全、但尚未成功同步的连接返回 `UNVERIFIED`，不再直接返回 `READY`。
* 成功同步写入 `last_sync_at` 后连接返回 `READY`；缺少部署配置和停用连接分别返回 `NOT_CONFIGURED`、`DISABLED`。
* 首次同步门禁改为检查 ACTIVE 与 `credential_configured`，确保 `UNVERIFIED` 连接可以完成验证。
* 数据导入页增加中文状态标签、首次同步引导和最近成功时间；重复请求命中 PROCESSING 运行时不再误报完成。

## 验证

* MMP Service 单测覆盖未验证连接与已有成功同步连接的健康派生。
* Vue 工具测试覆盖四态说明、首次同步门禁和中文状态映射。
* Go MMP 定向测试、Vue 定向测试与 TypeScript 检查通过；全量验证结果记录在交付说明中。

## 安全与兼容性

* 没有数据库 migration，状态完全由既有字段派生。
* API 没有增加凭证内容；`credential_configured` 仍为布尔值。
* 客户端若依赖原三态枚举，需要接受新增 `UNVERIFIED`；READY 的语义从“配置齐全”收紧为“至少一次真实同步成功”。
