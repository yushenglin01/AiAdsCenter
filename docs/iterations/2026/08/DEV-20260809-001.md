* 目标：为单公司 B 端内部成员补齐页面注册、邮箱确认、管理员授权和可审计的登录准入链路。

## 实现内容

* 成员状态使用 `PENDING_EMAIL`、`PENDING_APPROVAL`、`ACTIVE`、`REJECTED`、`DISABLED`，只有 ACTIVE 状态可登录。
* 注册限制在配置的公司邮箱域名内，用户名租户内唯一，密码至少 12 位并包含大小写字母、数字和特殊字符。
* 邮箱确认 Token 使用加密随机数生成，数据库只保存 SHA-256 摘要、有效期和消费时间；重发带冷却并失效旧 Token。
* 管理员可筛选申请、分配一个或多个角色、批准或填写原因驳回；SYSTEM_AGENT 不在可授予角色中。
* Vue 新增注册、确认和成员审核页面，覆盖配置加载、提交、等待、成功、错误及空状态。

## 接口与数据库

## 安全与回滚

* 注册与重发使用通用受理响应，避免通过邮箱枚举内部账号；审计元数据不保存密码或原始 Token。
* 管理员授权由服务端 RBAC 和事务状态条件强制执行，不能仅靠前端隐藏按钮。
* down migration 会删除注册资料和邮箱确认记录；回滚前应停止注册入口并备份需要保留的成员审核信息。
