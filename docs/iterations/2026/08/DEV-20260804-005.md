## 回滚方案

1. 停止 api，禁止新 Agent 任务写入并备份 agent_tasks/model_usage_records/schema_migrations。
2. 人工执行 `000005_version_agent_contracts.down.sql`；确认字段删除后删除 schema_migrations 中 000005 记录。
3. 回退 0.4.0 镜像与配置，恢复旧 Prompt loader；旧 Prompt 文件仍在。
4. 若只需应用回滚，可保留新增列和 migration history，0.4.0 会忽略额外列；这是优先方案。
5. 回滚会丢失 prompt_name/schema_version/schema_name 的新增值，不会删除 Agent 任务主体。禁止自动执行 down 或在无备份时回滚。
