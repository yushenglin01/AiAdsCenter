# ADR-0007：使用持久化工作流编排多 Agent

* 状态：Accepted
* 日期：2026-08-04

## 决策

七类 Agent 不通过自由文本互相对话，而是通过版本化输入、结构化输出和 workflow_steps 交接。确定性 Agent 同步执行，Business Agent 保持 Outbox/Asynq 异步执行；工作流通过持久化业务任务 ID 对齐其状态。

Research 与外部 OpenClaw 连接器未配置时必须显式降级，不允许使用模型填充不存在的来源或发送结果。审批和广告平台执行边界保持不变。

## 结果

系统能够展示每个 Agent 的职责、状态、输出和失败位置，并在进程重启后恢复查询。代价是工作流目前通过详情读取触发异步状态对齐；后续可增加 Worker 回调或事件消费者，但不得绕过持久化状态机。
