# ADR-0002：Agent 仅通过受限工具访问业务能力

* 状态：Accepted
* 日期：2026-08-04
* 决策迭代：DEV-20260804-004

## 背景

经营分析需要模型生成解释和建议，但广告预算、关键指标与公司数据属于高风险边界。让模型直接访问数据库、Shell、任意 HTTP 或广告平台会造成越权、幻觉执行和不可审计风险。

## 决策

Agent 定义为 `AgentSpec + Prompt + Tools + Permissions + Model + OutputSchema`。指标由确定性代码计算；Agent 只能调用白名单工具；输出必须经过证据、置信度、动作和审批规则校验。高风险建议只生成 `PENDING` 审批请求，系统不提供外部广告修改工具。

## 结果

模型错误会被限制在建议层，所有输入、尝试、用量、输出和审批请求可追踪。代价是增加了工具契约与校验维护成本，但这是可接受的安全成本。

## 回滚或替代

可关闭真实 Provider 并切回稳定 Mock；不得通过放宽工具注册或绕过 Validator 来解决模型兼容问题。
